InteractiveBOM Suite V1.0.01 版本说明

发布日期：2026-09-28
基线：InteractiveBOM Suite V1.0.00（基于 InteractiveHtmlBomForAD，master v0.3.17）

V1.0.01 为 V1.0.00 的补丁版本，仅修正「丝印」导出行为，无新增功能、无文件增减。


一、修正内容

1. 「丝印」按钮改为直接导出 PDF 文件（不再依赖浏览器打印）
  - 原问题：点击「丝印」会弹出空白标签页，把顶/底两层丝印渲染成图片后调用浏览器打印，
    指望用户在打印对话框里手动「另存为 PDF」。该链路易断——对话框不弹、或另存为 PDF 失败时，
    页面只剩一个无法保存的空白页（即此前反馈的"跳转成页面、另存为不行"）。
  - 新行为：点击「丝印」现在直接生成真正的 PDF 文件并弹出「另存为」对话框，可自选保存位置；
    浏览器不允许自选位置时自动降级为下载并给出提示（与「BOM 导出 Excel」流程一致）。
  - 实现细节（沿用本项目零依赖风格）：
    顶层 / 底层各一页，渲染为 JPEG 图像（DCTDecode 直接内嵌）；标题文字直接画进图片，不嵌 PDF 字体；
    A4 按板框横/竖自动选向，图像等比居中，单层绝不跨页。

2. 其余功能与 V1.0.00 完全一致（详见《版本更新说明_V1.0.00.txt》）。


二、受影响文件

  - web/util.js：重写 printSilkscreen()，浏览器打印改为手写 PDF 生成 + 另存为。
  - web/ibom.js：页面页脚品牌版本号 V1.0.00 → V1.0.01。
  - README.md：标题与说明链接版本号更新。

历史页面（V1.0.00 导出的 HTML）仍是旧行为；本修正需重新从 AD 导出 HTML 后生效。


三、安装与使用（与 V1.0.00 相同）

1. 安装
  1. 解压到任意目录。
  2. 运行一次 Initialize.bat（自动生成路径配置并拼接脚本产物）。

2. 导出
  1. 用 Altium Designer 打开 InteractiveBOMSuite.PrjScr。
  2. 打开 PCB 文件。
  3. Run Script... 运行 main()（或运行 dist\mainWin.js 走图形窗口）。
  4. 需要原理图时勾选「包含原理图（离线 SchDoc）」。
  5. 产物输出到 `<PCB 目录>\PnPout\<板名>.html`。

3. 使用导出页面
  - 双击 HTML 即可打开，离线单文件、无网络依赖。
  - 点击 BOM 行 / PCB 元件 / 原理图元件，三视图同步高亮定位。
  - 工具栏「BOM」按钮导出 Excel 物料清单。
  - 「丝印」按钮直接将顶层 / 底层丝印导出为 A4 PDF（另存为）。

4. 更新说明
  - 修改 AD 侧脚本后需重启 Altium Designer。
  - 仅更新 web/ 页面文件时，重新导出一次 HTML 即可。


四、换机使用

  - 换目录、换电脑只需重新运行一次 Initialize.bat，无写死的机器路径。
  - 原理图注入器自动查找 node.exe（config.ini 指定 → Program Files → 用户目录）；仍找不到时在 config.ini `[General]` 加一行 `NodePath=<node.exe 完整路径>` 即可。
  - 分发包内 rootPath.js 与 dist 产物中的路径为空占位（`var CURRENT_PATH = "";`），运行 Initialize.bat 后自动写入实际路径，属正常现象。


五、兼容性

  - 旧版导出的设置文件可直接导入，历史 HTML 页面可正常打开。
  - 导出页面为离线单文件，双击即可打开，无网络依赖。
